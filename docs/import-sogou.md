# 导入搜狗输入法

本仓库生成的是**用户文本词库**，不是 `.scel` 细胞词库。新版搜狗不能可靠地从 txt 生成 scel。

## 用哪个文件

导入请用 **GBK** 版：

- `dist/gbk/全部.txt`（足球 + 自行车）
- 或只导入 `dist/gbk/足球_曼城.txt` / `dist/gbk/自行车.txt`

`dist/utf8/` 仅供阅读和 Git 对照，新版搜狗导入 UTF-8 容易乱码或失败。

## 步骤

1. 在仓库根目录运行 `python scripts/build.py`（若 `dist/gbk/` 已是最新可跳过）。
2. 右键搜狗状态栏 → **设置属性** → **词库**。
3. 词库操作选择 **导入文本词库**，选 `dist/gbk/全部.txt`。
4. 编码若可选，选 **ANSI / GBK**。
5. 到记事本里打 `halande`、`huanfa`、`bogacha`，确认出现「哈兰德」「环法」「波加查」。

## 格式说明

文件是一行一个中文词，没有拼音串。新版搜狗按汉字自动绑定拼音。

## 更新词库后

YAML 改完并重建后，在搜狗里**再导入一次**同一文件。本流程不会自动写入输入法。
